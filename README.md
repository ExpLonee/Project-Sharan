# Titanic Survival Prediction 🚢

## Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning. The model is trained on the Titanic dataset and uses passenger information such as age, sex, ticket class, fare, and family details.

## Dataset
- Source: Kaggle Titanic Dataset
- Features used:
  - Passenger Class (Pclass)
  - Sex
  - Age
  - SibSp
  - Parch
  - Fare
  - Embarked
